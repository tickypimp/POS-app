ใส่เบอร์พร้อมเพย์หรือเลขบัตรประชาชนเพื่อให้ระบบสร้าง QR ให้อัตโนมัติ (ฝังยอดเงินให้เลย) หรือจะอัปโหลดรูป QR ของคุณเองก็ได้ — ถ้ามีรูปอัปโหลดไว้ ระบบจะใช้รูปนั้นแทนการสร้างอัตโนมัติ ข้อมูลทั้งหมดเก็บไว้ในเครื่องนี้เท่านั้น

ซิงก์เมนูกับ GitHub

บันทึกเมนูเป็นไฟล์ JSON บน GitHub Gist ส่วนตัว ใช้ Personal Access Token ที่มีสิทธิ์ gist เท่านั้น เก็บไว้ในเครื่องนี้เครื่องเดียว ไม่ส่งไปที่อื่น
